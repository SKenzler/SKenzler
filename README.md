#### Background

Embracing tech, this is where I'm at. So many frameworks and libraries to build from, not to mention some really incredible AI technologies to build smarter. I'm currently exploring Framer as a development tool but have also started to incorporate Codeium into my build process in VS Code. So many possibilities. It's an exciting time for designers and developers to push the possibilites of creativity.
